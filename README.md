# HOSPITAL.EXE™

A fictional static hospital parody website.

## Concept

**If a normal hospital website uses a photograph, HOSPITAL.EXE uses a comic strip.**

Facilities, doctors and services are demonstrated through short fictional comic sequences with absurd humor.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No backend
- No database
- No API
- No real patient data

## Pages

- Home
- Facilities
- Doctors
- Comic Archive

## Important

This is a fictional parody website. It is not a real hospital, medical service, diagnostic system, billing system, or source of medical advice.

## Run

Open `index.html` directly in a browser or deploy the repository to any static hosting service.
